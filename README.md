# ASO Lilit

Персональный **локальный MCP-наблюдатель** проекта Andreslav, работающий по stdio. Он не запускает фоновые службы, не открывает сетевые порты и не изменяет файлы проекта.

## Инструменты
- `health` — состояние наблюдателя
- `list_files` — список файлов в разрешённом каталоге
- `read_project_text` — ограниченное чтение текстовых файлов
- `git_status` — локальный статус Git
- `git_recent_commits` — история локальных коммитов

## Установка (Windows)
1. Клонируйте репозиторий в отдельную папку; не используйте существующий `D:\AHexaTrader\ASO_LILIT` как цель клонирования без предварительного сравнения файлов.
2. Скопируйте `config.example.json` в `config.json` и укажите свой абсолютный путь к Andreslav.
3. Запустите `py -3 -m venv .venv`.
4. Запустите `.venv\Scripts\python.exe -m pip install -r requirements.txt`.
5. Для stdio MCP-клиента используйте команду `.venv\Scripts\python.exe` с аргументом `server.py` и рабочим каталогом репозитория.

SDK ограничен версией **MCP 1.x**: версия 2.x несовместима с используемым импортом `FastMCP`.

## Безопасность
**Никогда не коммитьте** настоящий `config.json`, `.env`, токены, пароли, журналы работы или `.venv`. Файл `.gitignore` скрывает такие файлы только от обычного `git add`; он не защищает уже отслеживаемые файлы и не заменяет проверку перед публикацией.

Режим сервера read-only. Доступ разрешён только к заданным корневым каталогам. Сервер не предоставляет удалённый веб-доступ и сам по себе не подключён к веб-ChatGPT.

MCP DeepSeek — **отдельный проект**; его рабочие файлы здесь не хранятся.
